# 占星十二宫

## 十二宫是什么

宫位是本命盘的舞台。星座描述“如何”，行星描述“什么能量”，宫位回答“这件事发生在哪个生活领域”。出生时间决定上升点；上升点开启第1宫，其余宫位按逆时针依次展开。

一个常见误区是只记关键词。 reliable 解读要看四件事：落宫的行星、宫头星座、宫主星的位置与相位、当前行运是否触发该宫。

## 十二宫速览

| 宫位 | 主题 | 常见解读方向 |
| --- | --- | --- |
| 第1宫 | 自我与身体 | 外在形象、开端、身体感和第一反应 |
| 第2宫 | 资源与价值 | 收入、金钱、财产、能力、安全感 |
| 第3宫 | 沟通与近邻 | 学习、写作、兄弟姊妹、短途移动 |
| 第4宫 | 家庭与根基 | 家、父母、不动产、情绪根源、私人生活 |
| 第5宫 | 创造与恋爱 | 表达、娱乐、浪漫、孩子、冒险 |
| 第6宫 | 日常与照护 | 工作、习惯、健康、服务、流程 |
| 第7宫 | 关系与合作 | 婚姻、伴侣、契约、公开的一对一关系 |
| 第8宫 | 共享资源与转化 | 合并财产、亲密、债务、危机、深层改变 |
| 第9宫 | 远行与信念 | 高等学习、出版、异国、哲学、信仰 |
| 第10宫 | 事业与公众 | 职业、成就、社会角色、权威、声誉 |
| 第11宫 | 群体与未来 | 朋友、社群、组织、愿望、长期愿景 |
| 第12宫 | 潜意识与退隐 | 梦境、独处、疗愈、隐藏事务、灵性 |

## 角宫、续宫、果宫

第1、4、7、10宫是角宫，能量最外显；第2、5、8、11宫是续宫，偏向维持和发展；第3、6、9、12宫是果宫，偏向调整、学习和内在消化。这不是好坏分层，而是表达方式不同。

## 宫位制为什么不同

常用的宫位制包括 Placidus、Whole Sign、Porphyry、Equal House 等。它们划分宫头的方式不同，所以同一颗行星可能落入不同宫位。现代西占常用 Placidus，古典与当代简化解读也常用 Whole Sign。比较星盘时最好保持同一宫位制。
