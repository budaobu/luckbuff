# 占星術の12ハウス

## ハウスとは

ハウスはチャートの舞台です。サインは「どのように」、惑星は「どんなエネルギー」、ハウスは「どの生活領域で」を示します。アセンダントが第1ハウスを始め、残りが反時計回りに続きます。

キーワードだけの暗記は不十分です。ハウス内の惑星、カスプのサイン、ハウスルーラーの状態、トランジットの4点を見ると、読み方が安定します。

## 12ハウス一覧

| ハウス | テーマ | 主な意味 |
| --- | --- | --- |
| 第1 | 自己と身体 | 見た目、始まり、第一印象、自己認識 |
| 第2 | お金と価値 | 収入、資産、才能、自己価値、安心感 |
| 第3 | コミュニケーション | 学習、文章、兄弟、近隣、近距離移動 |
| 第4 | 家庭と土台 | 家、親、不動産、私生活、情緒的な土台 |
| 第5 | 創造と恋愛 | 遊び、芸術、恋愛、子供、健全な冒険 |
| 第6 | 日常とケア | 仕事、習慣、健康、奉仕、技術 |
| 第7 | パートナーシップ | 結婚、契約、顧客、一対一の関係 |
| 第8 | 共有と変容 | 共有資産、親密さ、借金、危機、深い変化 |
| 第9 | 意味と旅 | 高等学習、出版、外国、哲学、信念 |
| 第10 | キャリアと社会 | 職業、達成、権威、評価、社会的役割 |
| 第11 | 共同体と未来 | 友人、団体、ネットワーク、希望、将来像 |
| 第12 | 潜在意識 | 孤独、夢、癒し、隠れた事柄、撤退 |

## 角宮・継続宮・果宮

第1、4、7、10は角宮で動きが外に出やすく、第2、5、8、11は継続宮で維持と発展、第3、6、9、12は果宮で学びや調整に関わります。優劣ではなく表現の違いです。

## ハウス方式の違い

Placidus、ウェアハウス、ポルフュリー、イコールハウスなどは分割方法が異なります。方式によって同じ惑星が別のハウスに入ることがあるため、比較するときは同じ方式を使います。
