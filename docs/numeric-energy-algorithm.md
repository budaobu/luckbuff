# 数字能量共享算法说明

## 定版原则

数字能量学在民间存在多个版本。为了避免把某一个来源的原创解读照抄成本站“权威结论”，本项目整理了一版可程序化的常见体系：

- 以洛书九宫的一白至九紫作为 1–9 的星曜与五行基础。
- 数字相邻组合优先采用河图固定数理：1/6 归水，2/7 归火，3/8 归木，4/9 归金；5/0 在本工具内约定为土系锚点。
- 其余相邻组合按传统五行生克判读：同行为稳定延续，相生为流动支持，相克为张力、约束或保护性筛选。
- “0”不当成第十大星，而是中性占位与收束位，并归入土系锚点处理。
- 分数只用于展示相对侧重，不预测真实吉凶；结果页和海报均保留娱乐参考免责声明。

九星与五行映射如下：

| 数字 | 星曜 | 五行 | 展示侧重 |
| --- | --- | --- | --- |
| 1 | 一白贪狼 | 水 | 人缘、流动、机会 |
| 2 | 二黑巨门 | 土 | 稳定、照顾、承压 |
| 3 | 三碧禄存 | 木 | 行动、表达、竞争 |
| 4 | 四绿文曲 | 木 | 学习、沟通、文书 |
| 5 | 五黄廉贞 | 土 | 中枢、变化、转化 |
| 6 | 六白武曲 | 金 | 规则、纪律、权责 |
| 7 | 七赤破军 | 金 | 决断、突破、筛选 |
| 8 | 八白左辅 | 土 | 积累、不动产、稳健 |
| 9 | 九紫右弼 | 火 | 喜庆、人际、曝光 |
| 0 | 中性锚点 | 土（约定） | 占位、收束 |

场景差异只发生在输入提取规则、页面措辞、SEO 和海报标题；数字解析后的核心计算只有一份实现，位于 `server/utils/tools/numeric-energy.ts`。
