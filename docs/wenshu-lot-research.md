# 文殊菩萨灵签调研

调研日期：2026-09-17

## 结论

通行网络版本采用 100 签体系。主事实层使用签号、签题、签诗、吉凶、解曰、圣意；现代长文解释、场景化解签和签诗故事没有明确开源许可，未整段复用。产品中的“行动指引”为自写内容；AI 解签由用户问题、签诗与传统事实层生成。

交叉核对显示，51chouqian、guoxueju 的 1-100 签题和签诗一致，zhyczx 的抽样签诗/吉凶也一致。抽取后统计为上签 33、中签 32、下签 35。1、50、100 分别为“浮屠难登”“苏武脱难”“童人关求名”。

数据层修正两处源站明显笔误：`移徒` 归一为 `移徙`，二十四孝签题中的 `丁阑` 归一为 `丁兰`。

## 来源评估

| 来源 | 结果 | 用法 |
| --- | --- | --- |
| npm / GitHub 搜索 | 未发现维护中的文殊菩萨灵签结构化库或可许可 JSON 数据集 | 不引入 |
| `51chouqian.com/wenshupusa` | 1-100 连续页面，字段最完整 | 抽取事实层，并与目录页逐签校验 |
| `guoxueju.com/zhanbu/wenshupusa` | 1-100 连续页面，结构与 51chouqian 高度一致 | 抽样校验签题/签诗 |
| `zhyczx.com/wenshu` | 100 页，1/50/100 抽样一致 | 二次校验 |
| `zhouyi.cc/lingqian/wenshu` | 100 签，但 URL 为不连续文章 ID | 仅结构参考，不作主源 |

完整页面字段包含：签号、签题、签诗、吉凶、解曰、圣意、诗文解译、本签重点/隐喻、爱情婚姻、求职工作、创业事业、考试竞赛、升迁竞选、投资、经商、房地产、治病、转变、求孕、诉讼、远地发展、签诗故事。其中传统事实层进入产品；场景化现代解释和故事未搬运。

## SEO 依据

Google Autocomplete（`hl=zh-CN&gl=CN`）对“文殊菩萨灵签”返回：

- 文殊菩萨灵签 一枝独秀
- 文殊菩萨灵签 转怒
- 文殊 菩萨 求 什么
- 文殊 菩萨 善 财 童子
- 文殊菩薩 麒麟
- 文殊 菩萨 特征

扩展查询高频关联需求包括“求什么”“学业”“保佑”。来源页面一致确认 100 签。因此主标题组合为：

`文殊菩萨灵签在线抽签_100签解签与学业指引`

详情页标题使用稳定搜索结构：

`文殊菩萨灵签第{n}签解签_签诗与圣意详解`
