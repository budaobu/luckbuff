# Tieban Shenshu Data Notice

`tables.json` and `verses.json` contain only numeric lookup tables and Qing-dynasty
verse text used by the charting method. They do not include the upstream TypeScript
implementation, annotations, or method essays.

The source transcriptions were compared across the public repositories
`xaminxan/tiebanshenshu` and `Nanphy/TiebanshenshuOS`; only the public-domain
classical data rows were retained. Verse transcriptions have not been collated
against a printed Qing edition, so the UI labels them as uncollated research text.

No birth data is persisted by the charting tool.
