# 在线寺庙 /tools/sansatemple 功能规格（SPEC）

放置位置：`docs/sansatemple/SPEC.md`。这是 `/goal` 的唯一功能清单，Codex 不得自行增删条目；确需调整时写进 `PROGRESS.md` 的「偏离记录」并说明理由。

## 0. 来源与可信度

本清单依据 2026 年 10 至 11 月的公开报道与用户教程整理（韩国日报、连合新闻、ShareHows、make2t 等），原站首页是纯 JS 渲染，未能实机检视。每条功能带标签：

- 【已证实】多个独立来源一致描述
- 【推断】来源只有侧面描述，实现时取保守解释
- 【自拟】原站未证实，或用户额外指定的场景，按本规格自行设计

如果在 `docs/sansatemple/ref/` 放了原站截图或录屏，可作为布局和节奏的参考，但不得把其中的任何素材带进产品。

## 1. 产品气质（所有取舍的裁判标准）

安静、不打扰、不考核。没有聊天、没有排行、没有成就、没有登录。「合席但不搭话」是核心体验：同一座法堂里有别人，你们只能用合十互相打个招呼。文案克制朴素，不宣称功德、灵验或可替代真实宗教仪式。页面底部有一行说明：这是在线体验，不是真实寺院的法会或祈福服务。

|---|---|---|---|

| S4 | 法堂 | 林中开阔的殿堂，正中大佛像，地面布满坐垫（一垫一人），烛灯与窗光 | 已证实 |

建筑风格默认汉传寺庙（原站是韩式山寺，本项目面向中文用户）。场景结构、动线、功能与原站一致即可，不复制其具体造型。

## 3. 功能清单与验收项

### 入口与连接

- F-01 入口加载页：加载进度或「正在打开法堂」；连接失败出现重试按钮；无 WebGL 时降级为静态海报加一段说明；JS 禁用时显示 noscript 提示。【已证实】
- F-02 频道：默认 3 个频道，单频道容量默认 50（可由服务端环境变量调整，不带 `PUBLIC_` 前缀）；列表展示人数；满员频道不可进入，可选其他频道；全部满员时显示排队提示。原站为 100 个频道、每个 100 人，本项目按 VPS 承载能力缩小。【已证实，规模自拟】
- F-16 离开寺庙：菜单中有「离开」，点击后释放坐垫、断开连接、回到入口页，声音全部停止。【已证实】

### 化身与移动

- F-03 化身与名牌：进入时自动分配一个头顶名牌（形容词加自然物的中文组合，词库原创，例如「慢步」「静云」「善树」这一类气质，不得照抄原站词条），无需输入昵称。化身是原创的小沙弥形象，写实比例的风格化角色，不得复刻原站的童子僧造型。【已证实，造型自拟】
- F-04 移动与相机。【已证实】

| 操作 | PC | 手机 |
|---|---|---|
| 移动 | W A S D 或方向键；点击地面走到该处 | 虚拟摇杆或点击地面 |
| 环视 | 鼠标拖拽 | 单指滑动 |
| 缩放 | 滚轮 | 双指捏合 |
| 拜佛（开始/停止） | 1、E、空格 | 屏幕按钮 |
| 念珠 | 2 | 屏幕按钮 |
| 合十 | 3 | 屏幕按钮 |

键盘无响应时需要先点击画布获得焦点，并在设置里给出提示。

### 动作与互动

- F-07 合十：化身双手合十的动画；附近有他人时，对方收到轻提示「某某向你合十」（只提示，不能回复文字）。【已证实】
- F-08 拜佛：点击后化身自动走向最近的空坐垫，到位后循环做完整的拜姿（站立、跪、俯身、起身）；再点一次停止并起身。走向坐垫的过程中允许取消。坐垫由服务端裁决，一垫一人。不做「自动计满 108 拜」，也不做完成认证；个人拜数可选择性地只记在本机 localStorage 并显示在设置里。【已证实，计数自拟】
- F-09 念珠：进入独立视图，一串 108 颗念珠，上下滑动（手机）或鼠标拖动、滚轮、方向键（PC）逐颗拨动，计数 `n/108` 实时变化，有返回按钮回到法堂。念珠计数是个人本机计数，可存 localStorage；与拜数互相独立。每拨一颗有轻微触感反馈（手机震动，有则用）和一声轻响。【已证实，持久化自拟】
- F-10 木鱼：在坐垫上或香案旁可敲木鱼，点击或按键敲击一次出一声，有轻微的视觉反馈（木鱼与木槌动画，不做夸张特效）。允许连续敲击，限制最大频率避免音频叠爆。【推断，Joey 指定】
- F-11 烧香：在香案处取香、点燃、插入香炉；香有燃烧时长（约 3 分钟，渐短、轻烟粒子），燃尽后消失；每人同时最多插 3 支；香炉里能看到所有人插的香。不做付费或供养机制。【自拟，Joey 指定】
- F-12 打坐：在坐垫上进入静坐姿态（盘腿、闭眼、轻微呼吸起伏）；可选计时 5、10、20 分钟，结束时一声磬；静坐期间镜头缓慢拉近，界面控件淡出，点击任意处恢复。【自拟，Joey 指定】

### 声音

- F-13 声音系统。【已证实，部分自拟】
  - 设置面板含：总开关、环境音（风声鸟鸣等）、诵经（个人听/共同听）、音效（木鱼、念珠、磬、钟）四类，各自独立音量。
  - 切到后台标签页时所有声音暂停，回来后恢复。
  - 设置持久化在 localStorage。
  - 首次进入需用户手势后才开始播放（浏览器自动播放策略）。
  - 诵经音源必须是已授权资产；如果没有，用程序合成的木鱼节拍加磬声作占位，在 `ASSETS.md` 标注「待替换」，不得阻塞其他工作，也不得使用任何来源不明的录音。原站设置页曾显示「心经完整音源尚未选定」，说明这一块原站自己也在变，不要求完整诵读。
- F-14 早晚课共修：每天 05:00 与 18:00（Asia/Shanghai，常量集中配置）。设置里显示下一场倒计时；开始后「个人听」自动切换为「共同听」，所有在场者同一时间线播放，结束后恢复。服务端以时间戳下发起播点，客户端据此对齐。【已证实，时间自拟】

### 多人

- F-15 同堂：同一频道内的化身位置、朝向、动作状态实时同步；没有任何文字聊天或表情包；坐垫占用、烧香、合十提示通过服务端广播。断线自动重连，重连失败回到入口页并提示。位置同步频率不高于 5 次/秒，带量化与增量，服务端对每个连接做限流（不超过 10 条/秒），超出直接丢弃。服务端只保存内存态，不落库，不记录 IP，不收集任何个人信息。优先使用 Nitro 内置 WebSocket（crossws），先确认当前 Nitro 版本支持；若不支持，退回为单独的轻量 `ws` 服务脚本，但不修改 PM2 与 Nginx 配置，只在 `DEPLOY-NOTES.md` 写出需要的 Upgrade 头与反代片段，交给 Joey 手动部署。【已证实】

### 性能与降级

- F-17 画质分级：沿用本项目已有的三档自动降级与静态海报兜底做法（参考掷筊杯、摇签与八字三维化的约定）。初始预算如下，Codex 可在记录理由后调整不超过 30%。

| 项目 | 高档 | 中档 | 低档（手机） |
|---|---|---|---|
| draw calls | ≤ 250 | ≤ 150 | ≤ 80 |
| 三角面 | ≤ 600k | ≤ 350k | ≤ 150k |
| 首屏可交互资源（压缩后） | ≤ 12 MB | ≤ 9 MB | ≤ 6 MB |
| 同屏骨骼化身 | ≤ 30 | ≤ 20 | ≤ 10 |

超出同屏骨骼上限的远处化身使用实例化、低模或静态替身。模型用 Draco 或 Meshopt 压缩，贴图用 KTX2 或 WebP，音频按需懒加载。

### 站点集成

- F-18 移动端适配：`viewport-fit=cover`、安全区、横竖屏、`theme-color`、`apple-mobile-web-app-capable`，界面按钮不被浏览器底栏遮挡。【已证实】
- F-19 站点集成：按仓库现有约定注册到 tools 列表与站点地图；`useSeoMeta` 加 JSON-LD，`site_name` 来自配置，不硬编码；i18n 只新增 key，不改动已有 key；纯客户端渲染（`ClientOnly`）；不使用「幽默隐士」作为可见署名。【项目约定】
- F-20 说明与致谢：页脚一行体验说明（非真实仪式），以及一行灵感来源致谢并链接 sansatemple.com（不使用其名称、标志、封面图）。致谢行是否保留由 Joey 决定，默认保留。【自拟】
- F-21 可访问性：全部交互可用键盘完成；`prefers-reduced-motion` 时关闭镜头缓动与粒子；关键提示有文字，不只靠声音。【自拟】

## 4. 资产与许可

- 模型、贴图、音频只能来自：本项目自建（优先 Blender 无头脚本或程序化几何）、CC0 或明确可商用的来源（记录来源、作者、许可证与链接）。所有资产登记到 `docs/sansatemple/ASSETS.md`。
- 先检查环境里是否有可运行的 `blender`（`blender -b`）；有则用 Python 脚本生成并导出 GLB；没有则用 three.js 程序化几何加程序化贴图起步，先让整套交互跑通，再替换为精修资产。
- 木鱼、磬、钟、念珠声、风声鸟鸣优先用 Web Audio 合成或 CC0 采样；不得使用从任何寺庙、网站、视频里截取的录音。
- 不抓取、不反编译、不下载 sansatemple.com 的脚本、模型、音频、贴图或接口流量。
- 「实景实物实人」的落地口径：实景是 PBR 材质加烘焙光照的写实风格寺庙；实物是高精度道具（佛像、香炉、念珠、木鱼、坐垫、灯笼）；实人是写实比例的风格化小沙弥，带骨骼动画。照片级真人 100 人同屏在手机浏览器里做不到，不在范围内。

## 5. 明确不做

聊天与表情、供养或打赏、登录与账号、排行榜与成就、功德数值、任何灵验类宣称、真实寺院的法会与祈福接单、原站素材与品牌。
