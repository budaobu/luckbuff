# 皇极经世排盘算法说明

工具路由：`/tools/huangji-paipan`，计算核心：`server/utils/huangji/paipan.ts`。

## 结论

完整排盘按“元 → 会 → 运 → 世 → 年”展开：

- `1元 = 12会 = 360运 = 4320世 = 129600年`
- `1会 = 30运 = 10800年`
- `1运 = 12世 = 360年`
- `1世 = 30年`
- 皇极积年 = `67017 + 公元年`；1900-2100 是当前 API 明确支持范围。

输出层级包括：元卦、四时正卦、节卦、会卦、2160 年卦、360 年运卦、原始 60 年世卦、跳过四正后的 60 年甲子卦、十年卦、值年卦和世内五年值爻。

## 选型

不引入 GPL 或无许可证代码。`Ryanlyly-ai/huangji-jingshi` 为 MIT，且其文档声明 129600 行配表已逐行审计；`react-yhys` 与 `kinwangji` 虽然可作资料比对，但缺少可商用许可证或采用 GPL，因此不作为依赖。实现继续复用仓库既有六十四卦与爻辞数据，按公开算法自建 TypeScript 核心。

## 口径与证据

- 元会运世骨架为传世本原文明载；尧元年、公元前 87 年、公元 544 年等锚点沿用 `docs/huangji-zhiniangua-algorithm.md` 已交叉验证结论。
- 年度配卦采用马振国、曾华才 2020 现代重建口径，并用 MIT 实现的算法规范与 Suhe.space 值年卦推算法交叉比对。结果在 UI 中明确标注“现代重构”，不冒充邵雍唯一原法。
- 2026 年回归样例：皇极积年 69043；午会第 4243 年；乙 192 运第 283 年；酉 2302 世第 13 年；2160 年卦为泽风大过，360 年运卦为天风姤，60 年甲子卦为火风鼎，十年卦为天风姤，值年卦为天火同人。
- 1984-2043 年六十个值年卦互不重复；首年为火风鼎，2026 年为天火同人，末年为泽风大过。
