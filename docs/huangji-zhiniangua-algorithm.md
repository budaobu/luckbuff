# 皇极经世·值年卦算法说明

工具路由：`/tools/huangji-zhiniangua`，计算核心：`server/utils/huangji/core.ts`。

## 一、纪元锚点（两个独立资料源交叉验证）

**锚点年份：帝尧元年 = 甲辰 = 公元前2357年（天文纪年 -2356）**

- 来源 1：祝泌《皇极经世解》用卦案例（https://www.zhouyi64.com/newsnw/id/1075）：
  「唐尧于二千一百五十六世岁次甲辰(公元前2357年)即位」。第 2156 世与积年
  64661 互相印证：2155 × 30 + 11 = 64661（尧元年为该世第 11 年）。
- 来源 2：知乎《以皇极经世历法计算2022年》（https://zhuanlan.zhihu.com/p/577304331）：
  现行一元起点为公元前 67017 年，尧元年积年 = 67017 − 2357 + 1 = 64661。
- 干支旁证：1984 = 甲子，(−2356 − 1984) mod 60 = 40 → 甲辰，与「尧元年甲辰」一致。

**锚点年值年卦：雷火丰（六十卦序列 index 12）**

- 来源 1：《皇极经世年卦表(1984到2043值年卦)》（http://www.njmingdinghui.com/y/3076367/）：
  2024 甲辰年 = 雷火丰。
- 来源 2：suhe.space《值年卦及其推算法》（https://docs.suhe.space/en/docs/iching/other/doc-38/）：
  从公元前 67017 年元起点经元→会→运→世逐层推得 1984 = 鼎，按方圆图顺序逐年推进
  （遇乾坤坎离跳过），2024 = 丰。
- 桥接：公元前 2357 年与公元 2024 年同为甲辰，相距 4380 = 73 × 60 年整，
  在连续扁平六十卦循环下两年同卦，故尧元年 = 丰。
- 流派备注：祝泌层叠法（60 年一重置、按运卦爻变起世）推尧元年岁卦为火天大有，
  与本工具采用的连续扁平循环口径不同。两法在 1984–2043 段内一致，跨段分歧。
  经用户确认，本工具采用与现代流传值年卦表自洽的「丰」锚点。

## 二、六十卦固定循环

先天六十四卦圆图去除乾、坤、坎、离四正卦后的 60 卦，顺序为：

复、颐、屯、益、震、噬嗑、随、无妄、明夷、贲、既济、家人、丰、革、同人、
临、损、节、中孚、归妹、睽、兑、履、泰、大畜、需、小畜、大壮、大有、夬、
姤、大过、鼎、恒、巽、井、蛊、升、讼、困、未济、解、涣、蒙、师、遯、咸、
旅、小过、渐、蹇、艮、谦、否、萃、晋、豫、观、比、剥

目标年 Y 的取位：`index = (Y + 2368) mod 60`（2368 = 2356 + 12，
即锚点天文纪年偏移 + 锚点卦丰在序列中的位置）。

## 三、从卦到爻

- 皇极经世积年：`jinian = 67017 + Y`。
- 一卦统一个 30 年的「世」，世内年第几年：`yearInShi = (jinian − 1) mod 30 + 1`。
- 一卦六爻各管 5 年：`yaoPosition = ceil(yearInShi / 5)`
  （1–5 年初爻，6–10 年二爻，11–15 年三爻，16–20 年四爻，21–25 年五爻，26–30 年上爻）。
- 取该值年卦对应爻的爻辞；按「阳爻居奇位、阴爻居偶位」判当位与否，
  与爻位阶段（初/二/三/四/五/上）组合生成确定性大势走向文本。

## 四、人工可核验演算样例

### 样例 1：1900 年（庚子）

1. **积年换算**：积年 = 67017 + 1900 = 68917。
   世内年 = (68917 − 1) mod 30 + 1 = 68916 mod 30 + 1；
   68916 = 30 × 2297 + 6 → 世内第 7 年（世范围 1894–1923）。
2. **六十卦取位**：index = (1900 + 2368) mod 60 = 4268 mod 60 = 8
   （4268 = 60 × 71 + 8）→ 序列第 8（从 0 计）= **地火明夷**。
   回验：1900 − (−2356) = 4256，4256 mod 60 = 56；(12 + 56) mod 60 = 8 ✓
3. **爻位确定**：第 7 年 ∈ [6,10] → 二爻。明夷下离上坤，二爻为阴 → **六二**，
   阴居偶位 = 当位。爻辞：「明夷于飛，垂其翼。君子于行，三日不食。有攸往，主人有言」。
   大势走向：「世运渐启，崭露头角，居中得道而渐兴。值年卦地火明夷，
   爻当其位，顺天应时，此五年大势稳中向好。」

### 样例 2：2026 年（丙午）

1. **积年换算**：积年 = 67017 + 2026 = 69043。
   世内年 = (69043 − 1) mod 30 + 1 = 69042 mod 30 + 1；
   69042 = 30 × 2301 + 12 → 世内第 13 年（世范围 2014–2043）。
2. **六十卦取位**：index = (2026 + 2368) mod 60 = 4394 mod 60 = 14
   （4394 = 60 × 73 + 14）→ 序列第 14 = **天火同人**。
   回验：与 2024（甲辰，丰，index 12）相隔 2 年，(12 + 2) mod 60 = 14 ✓
3. **爻位确定**：第 13 年 ∈ [11,15] → 三爻。同人下离上乾，三爻为阳 → **九三**，
   阳居奇位 = 当位。爻辞：「伏戎于莽，升其高陵，三歲不興」。
   大势走向：「世至中段，多忧多惧，进退之际变革酝酿。值年卦天火同人，
   爻当其位，顺天应时，此五年大势稳中向好。」

两个样例相隔 126 年（>60），覆盖积年换算、六十卦取位、爻位确定三步，
均可手工复算。
