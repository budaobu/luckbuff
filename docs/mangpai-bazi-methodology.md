# 盲派八字方法论边界

本工具只把方法论写进服务端 system prompt，不在前端建立硬编码断语表；排盘仍由现有 BaZi 四柱与大运引擎完成。

## 计算口径

- 四柱、五行、格局、喜忌与大运：调用现有 BaZi 引擎，不改其对外行为。
- 流年：用现有流年干支函数生成当前年份起的连续六年，并用现有十神与地支关系函数标注。
- 十二神煞：太岁、青龙、丧门、六合、官符、小耗、大耗、朱雀、白虎、贵神、吊客、病符，按题定口径以流年地支起太岁，再依子丑寅卯辰巳午未申酉戌亥顺行。命局四支按同一循环对号入座。

## 交叉校验

断语规则综合两类独立脉络，不逐字引用任何书稿、网站口诀集或讲义原文：

1. 传统干支命理脉络：以天干地支、十神、宫位、刑冲合害与流年引动为共同底座，参照《渊海子平》《三命通会》《子平真诠》一系对宫位、用神与岁运应期的通行整理。
2. 盲派技法脉络：以取象、做功、宾主体用、宫位六亲和应期为解释框架，参照现代盲派命理教学中对段建业、郝金阳一脉技法的通行总结。

两线只用于约束推理方式：先看谁为主、谁为宾，能量是否成做功；再以宫位和十神定六亲事项，用合冲刑害判断开合、阻碍与引动时间；十二神煞只作流年象意补充，不单神定吉凶。

## 合规转换

- 健康：只说节奏、压力、作息、情绪等倾向，不诊断疾病，不给治疗方案。
- 官非：只说文书、规则、合作边界等压力，不认定案由或结果。
- 寿元、重症、死亡：一律转为阶段性提醒，不断死期、不断绝症。
