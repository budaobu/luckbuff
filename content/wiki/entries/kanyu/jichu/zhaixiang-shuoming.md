# 宅相参详使用说明：怎么测、怎么标、怎么读

宅相参详把沈氏玄空飞星、八宅大游年、紫白流年与通书择日四样东西叠在一座房子上。第一次用，照下面五步走，三分钟起盘；看不懂盘面，看第二节；名词不认识，看第三节。

## 一、三分钟起盘

**第一步 · 定向。** 站在屋内、面朝大门外，你面对的方向就是「向」。手机平放、顶端朝大门外，点「用手机实测」，读数稳定后点「锁定此读数」；没有手机罗盘就拖罗盘指针，或直接点「朝南」「朝东北」这类方位片，再在向度框里微调。玄空用磁针立向，手机读数直接可用，不必修正磁偏角；钢筋楼体读数会漂三五度，多测两次取稳定值。楼房不知道朝向：以入户门朝向为准；入户门开在侧面走廊而采光阳台朝向明确的，切到「以采光面为向」。

**第二步 · 定运。** 填入住年份（大装修后重新入住也算一次「立极」）；不确定就按当下九运（2024–2043）。立春换运，元旦到立春之间仍属上一年。

**第三步 · 布宫。** 把房子按方位切成三乘三九格，北朝上——这就是九宫。点任意一格，给它打上「大门 / 主卧 / 厨房……」的签，可多选；至少标大门、主卧、厨房三处，参详才有落点。有户型图就叠上去：把图的北对准栅格右上角的指针，房子中心落在中宫，用旋转 / 缩放 / 平移滑杆对齐。懒得逐格点，可以用「AI 智判布宫」：先看一眼图上的指北针、点选「图中北朝哪边」（多数户型图北朝上），再点智判，识别结果自动预填到九宫——它是预填不是定论，逐格核对、点错就改。隐私口径分两层：叠图对齐只在你的浏览器里完成，不上传；智判是显式动作，点了才把图压缩上传做一次识别，识别完即弃、不落库不存档。习惯「大门在下」看图的，勾「向朝下」。

**第四步 · 人宅（选填）。** 只要出生年与性别就能定命卦，看东西四命与宅相配、门和床头在不在本命吉方；带上年月日时还能并看八字喜用方位。配偶或同住家人也可再挂一位，床头按两人共同吉方定。

**第五步 · 择日（选填）。** 入宅、搬家、安床、动土四类；动土可指定动哪一方，系统会按月五黄、日五黄到方减分，并提示年五黄、太岁、三煞在此方的整年告诫。

点「起盘」，全部盘面免费摊开。付费分两档：「宅相参详」是 AI 依这份盘面写的七节长文（总览 / 逐宫 / 门主灶卧 / 人宅 / 流年 / 布置 / 结语），约三四千字；「全宅参详」扩到九节约五六千字——加「逐室详参」（你标的每间房独立成段，卫浴阳台也不略过）与「特别关注」（楼层、窗外、门前道路、周边水体这些引擎看不见的形势，逐项列成核对清单给判读方向）。

## 二、怎么读这张盘

- **每格两个大数字**：左边是山星，管人丁健康，卧室、书房看它；右边是向星，管财禄纳气，大门、客厅、阳台看它。小字「运」是运星，「年」是今年的流年星。
- **颜色**：竹青 = 当令、生气、进气（旺），土褐 = 退气（平），朱砂 = 衰、死、五黄（慎）。二黑与五黄哪怕按运属生进，也不涂竹青——病符之性不因进气而改。
- **角标**：「坐」是房子背靠的那一格，「向」是朝向的那一格；「年五黄」标的是今年五黄所在。
- **点任一格**，能看到这一宫山向二星组合的象义，分「旺相时」与「衰死时」两读——按格子的颜色选一读，旺相读旺、衰死读衰。
- **总评分**是账本加总：点「看这 N 分怎么来的」逐条可核。它是线索，不是判决；引擎不懂楼高、窗向、道路与水体，那些要你自己补进参详的「特别关注」里。
- **四大格局**：旺山旺向最好；双星到向财旺丁弱；双星到坐丁旺而财平；上山下水最差，可借城门补救。一运与九运本来就没有旺山旺向与上山下水，不是算错。
- **宅运不等于当运**：八运入住的房子到了九运，格局仍按八运盘立，但每颗星的旺衰按九运重算——这是「格局以立极之运论、旺衰以当下之运论」。

## 三、名词速查

- **元运 / 当令**：二十年一运，当运之星为当令（九运为九紫）；下一运为生气，再下一运为进气；上一运退气，其余衰死。
- **五黄**：正关煞，非当令时为首凶，所到之方忌动土。
- **二黑**：病符星，所到之方宜干爽通风。
- **山星 / 向星 / 运星**：山星主丁、向星主财、运星是底盘。
- **正向 / 兼向 / 替卦**：向度在本山正中三度内为正向；超过三度为兼向，改用替星入中。
- **出卦 / 空亡**：兼到了别的卦叫出卦；向度压在两山交界线上叫骑线空亡，建议复测。
- **城门诀**：向宫两旁合生成之宫，运星入中逆飞能令当运星回到该宫，则该方有路口、水口可借以引气。
- **入囚**：中宫向星所值之运到来时，财气受困于中宫。
- **八宅四吉四凶**：生气、天医、延年、伏位为吉；绝命、五鬼、六煞、祸害为凶。门、主卧宜吉方，灶、卫浴宜压凶方。
- **东四命 / 西四命**：命卦属坎离震巽为东四，乾坤艮兑为西四；与宅同类为相配。
- **太岁 / 岁破 / 三煞**：按年支定的三个忌动土之方。
- **建除 / 黄道**：择日的两层——建除十二神看日子的性质，黄道黑道看当日与时辰的天神。

## 四、常见问题

**手机罗盘读数跳来跳去？** 远离金属与电器，多测三次取稳定值；钢筋楼体差三五度是正常的。若提示「骑线」，说明向度压在两山交界，务必复测。

**合租一间房、宿舍一张床也能看吗？** 能。把这一间房当一套宅：以房门为向，九宫按这一间切。床头朝本命吉方是最轻量的用法，不需要改任何东西。

**不知道入住年份？** 按当下九运。与实际八运宅的差别在各星旺衰，不在格局。

**东西四命和宅不配怎么办？** 床头、书桌朝本命吉方；门改不了就把玄关做得明亮整洁。不配是可以调的，不是住不得。

**为什么没有「摆件」？** 宅相参详只论布置：动静、明暗、干湿、色调、朝向、绿植与金属的五行泄克——这是古法的本意。任何「买个东西就好」的说法都不在此列。

**户型图会被上传吗？** 叠图对齐只在你的浏览器里，不上传。只有点「AI 智判布宫」才会把图压缩后上传做一次识别，识别完即弃、不落库不存档；不点就永远不传。

**智判认错了怎么办？** 识别只是预填，不是定论——逐格核对、点错就改。最要紧的是北向：北向选错整盘会转错，点智判前先看一眼图上的指北针。识别免费，换张更清晰的图重认也行。

**免费与付费差在哪？** 免费层已经给出全部盘面与规则判语；付费层是 AI 把这些盘面写成一份有主次、有取舍、有具体布置动作的参详——基础档七节约三四千字，全宅档九节约五六千字（加逐室详参与特别关注），都可续问。

**这是「铁口直断」吗？** 不是。它是对一座房子的方位、时运与人的命卦做传统文化参详，讲的是气之顺逆与布置调适，不涉任何吉凶承诺，也不构成置业、居住、装修与医疗建议。
