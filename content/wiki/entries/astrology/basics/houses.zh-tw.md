# 占星十二宮

## 十二宮是什麼

宮位是本命盤的舞台。星座描述「如何」，行星描述「什麼能量」，宮位回答「這件事發生在哪個生活領域」。出生時間決定上升點；上升點開啟第1宮，其餘宮位按逆時針依次展開。

一個常見誤區是只記關鍵詞。可靠的解讀要看四件事：落宮的行星、宮頭星座、宮主星的位置與相位、當前行運是否觸發該宮。

## 十二宮速覽

| 宮位 | 主題 | 常見解讀方向 |
| --- | --- | --- |
| 第1宮 | 自我與身體 | 外在形象、開端、身體感和第一反應 |
| 第2宮 | 資源與價值 | 收入、金錢、財產、能力、安全感 |
| 第3宮 | 溝通與近鄰 | 學習、寫作、兄弟姊妹、短途移動 |
| 第4宮 | 家庭與根基 | 家、父母、不動產、情緒根源、私人生活 |
| 第5宮 | 創造與戀愛 | 表達、娛樂、浪漫、孩子、冒險 |
| 第6宮 | 日常與照護 | 工作、習慣、健康、服務、流程 |
| 第7宮 | 關係與合作 | 婚姻、伴侶、契約、公開的一對一關係 |
| 第8宮 | 共享資源與轉化 | 合併財產、親密、債務、危機、深層改變 |
| 第9宮 | 遠行與信念 | 高等學習、出版、異國、哲學、信仰 |
| 第10宮 | 事業與公眾 | 職業、成就、社會角色、權威、聲譽 |
| 第11宮 | 群體與未來 | 朋友、社群、組織、願望、長期願景 |
| 第12宮 | 潛意識與退隱 | 夢境、獨處、療癒、隱藏事務、靈性 |

## 角宮、續宮、果宮

第1、4、7、10宮是角宮，能量最外顯；第2、5、8、11宮是續宮，偏向維持和發展；第3、6、9、12宮是果宮，偏向調整、學習和內在消化。這不是好壞分層，而是表達方式不同。

## 宮位制為什麼不同

常用的宮位制包括 Placidus、Whole Sign、Porphyry、Equal House 等。它們劃分宮頭的方式不同，所以同一顆行星可能落入不同宮位。現代西占常用 Placidus，古典與當代簡化解讀也常用 Whole Sign。比較星盤時最好保持同一宮位制。
