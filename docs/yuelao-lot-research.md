# 月老灵签数据源调研

调研日期：2026-09-16。

## 结论

采用“杭州白云庵月下老人祠一系集句签 / 台湾庙本通行次序”的 100 支签作实现基础。该体系每签包含签号、吉凶等级、集句签诗，可考时补充原典出处；现代网站常见解释层另有求签说明、白话解签、具体事项判断，但没有统一开放许可。

不要把下面几类同名系统混合成一套：

- “月老灵签”：搜索和多个网页通行版本为 100 签。
- “月下老人灵签”：另有 60 签或 61 签系统，签文体系不同。
- 少数网页写 101 签：常见口径是“签王 + 百签”或网页标题不准确。本次可稳定核对和访问的编号是 1-100，因此不虚构第 101 支。

## 内容模型

完整的月老灵签结果至少应区分这些层次：

1. 事实层：签号、吉凶等级、签诗、原典出处、异文与版本说明。
2. 传统解释层：白话解签、注解、典故、吉凶成因。
3. 问事层：感情、暧昧、复合、婚姻、桃花等不同问题下的指引。
4. 交互层：所问之事、抽签流程、AI 个性化解读、免责声明。
5. 分发层：签号索引、单签详情页、分享图、结构化数据。

本实现只固化公共领域事实层：`app/data/yuelao-lots-100.json` 存储 1-100、九等吉凶、签诗和已知出处；解释层由既有 AI SSE 按用户所问生成，不复制第三方现代解释文本。

## 吉凶等级

抓取的 100 签出现十个等级：上上大吉、上上、上吉、上、中上、上平、中平、中、下平、下。实现里映射为五组展示色：

- 上上大吉 / 上上 / 上吉 / 上：`upper`
- 中上 / 上平：`upper-middle`
- 中平 / 中：`middle`
- 下平：`lower-middle`
- 下：`lower`

约半数签可考出原典出处，其余保留空值并在界面显示“出处未考”，不用推断补齐。
