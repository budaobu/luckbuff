# 地藏王菩萨灵签调研

调研日期：2026-09-17

## 结论

通行网络版本采用 60 签体系，每签由干支、签诗、米力仙注和白话简析组成。该体系没有统一的上中下吉凶等级；产品显示为“无固定吉凶”，避免把不同来源的解释误改成签等。

主事实层使用签号、干支、签诗和米力仙注。来源中的“明善堂白话简析”“签文解读”“建议”属于现代解释文本，且未声明可复用许可，产品不整段搬运。产品静态层的“签象提示”和行动提示为自写内容；AI 解签再按用户所问之事生成。

抽取后核对 1、30、60 三点：干支依次为甲子、癸巳、癸亥。简体源站第 60 签的“九州岛”归一为“九州”；繁体层使用 OpenCC 台湾转换。
