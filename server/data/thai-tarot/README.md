# Thai tarot data

`cards.json` is a structured extraction of all 78 Rider-Waite-Smith tarot card
references from `iamlamure/thai-tarot-rws-skill`. The upstream project is MIT
licensed; see `LICENSE` for the required copyright notice.

The dataset intentionally does not include card scans. RWS images are public
domain in the United States but are not confirmed as public domain in every
jurisdiction, including EU territories.
